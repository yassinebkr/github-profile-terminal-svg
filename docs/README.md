# Animated GitHub Profile Terminal

This repository contains the self-contained SVG terminal displayed inside a
GitHub profile README. The terminal is generated by Python and styled after
Debian 13 and XFCE Terminal.

## Source tree

- `README.md` — animated profile graphic and two destination links
- `assets/terminal-template.svg` — SVG window, colors, typography and animations
- `assets/debian-open-use.svg` — locally preserved Debian vector artwork
- `assets/terminal.svg` — reproducible generated profile illustration
- `assets/pages-cta.svg` — link to the interactive web portfolio
- `assets/how-made-it.svg` — link to this generator's source
- `scripts/make_terminal.py` — standard-library Python SVG generator
- `scripts/validate.py` — SVG consistency and structural checks
- `docs/` — experiments, visual design notes and artwork credits
- `.github/workflows/validate.yml` — profile generator verification

## Reproduce the SVG

```bash
python3 scripts/make_terminal.py
python3 scripts/validate.py
```

The Python generator produces a single SVG with inline vector graphics,
an animated command reveal and a blinking cursor. GitHub renders this
standalone asset as an image inside the README.

## Complementary interactive project

[ShellFolio](https://github.com/yassinebkr/ShellFolio) is the separately
maintained, [public interactive terminal website](https://yassinebkr.github.io/ShellFolio/).
The primary SVG link opens ShellFolio with `?run=launch` to execute the read-only\nvirtual command `./launch-interactive.sh` on arrival. Both links use identical\n920 × 74 SVG dimensions and layout grids.\n\nIts browser application, JavaScript engine, tests, web demo SVG and web
documentation all live in its **own public repository**. The profile SVG
generator and its documentation belong here.

This repository is currently named `test` and will be renamed later,
before a standalone public release. A `How I made it` link in the README
already targets this repository.
